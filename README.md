## 🚀 Tentang Proyek
Website ini merupakan portal resmi dan pusat informasi interaktif untuk **LDK Al-Fath Telkom University**. Dirancang dengan desain modern, antarmuka responsif, dan performa tinggi untuk mendukung kegiatan dakwah kampus yang terintegrasi antara pimpinan pusat, departemen, hingga tingkat fakultas.

## ✨ Fitur Utama
- **Profil Terpusat**: Eksplorasi struktur kepengurusan secara dinamis dari tingkat pusat hingga fakultas.
- **SOP & Pengaduan**: Akses mudah ke Standar Operasional Prosedur (SOP) organisasi dan saluran aduan/aspirasi publik (seperti Al-Fath Mendengar, dll).
- **Sistem Kalender Otomatis**: Kalender hijriah dengan penanda otomatis untuk hari puasa sunnah dan peringatan hari besar Islam.
- **Responsif & Estetik**: Tampilan menawan berbalut *glassmorphism* dan *micro-animations* yang beradaptasi sempurna di berbagai perangkat (Mobile, Tablet, Desktop).

## 🛠️ Teknologi yang Digunakan
- **[React 18](https://react.dev/)** - *Library* UI utama
- **[Vite](https://vitejs.dev/)** - *Build tool* & *Dev server* super cepat
- **[TypeScript](https://www.typescriptlang.org/)** - Keamanan tipe data
- **[Tailwind CSS v4](https://tailwindcss.com/)** - *Utility-first styling framework*
- **[React Router DOM](https://reactrouter.com/)** - Sistem navigasi & *routing*
- **[Lucide React](https://lucide.dev/)** - Pustaka ikon modern

## 💻 Panduan Pengembangan (Local Development)

### Prasyarat
Pastikan Anda sudah menginstal **Node.js** (versi 18+) di komputer Anda.

### Instalasi & Menjalankan Aplikasi
1. *Clone repository* ini:
   ```bash
   git clone https://github.com/mhmmdragilpy/alfath.telkomuniversity.git
   cd alfathtelkomuniversity
   ```
2. Instal semua dependensi:
   ```bash
   npm install
   ```
3. Jalankan *development server*:
   ```bash
   npm run dev
   ```
4. Buka browser dan akses `http://localhost:5173`.

## 🌐 Panduan Deployment
Aplikasi ini sudah dikonfigurasi untuk rilis mudah di platform **[Vercel](https://vercel.com/)**.
1. Push kode terbaru Anda ke GitHub.
2. Tambahkan proyek baru di Vercel dan *import repository* ini.
3. Vercel akan otomatis mendeteksi *framework* Vite.
4. Klik **Deploy**! (Berkas `vercel.json` telah disertakan untuk menjamin sistem *routing* React berjalan lancar tanpa error `404 Not Found`).
